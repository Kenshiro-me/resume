# Aswin Unni P B - DevOps Portfolio

A futuristic, responsive personal portfolio built to showcase Aswin Unni P B's DevOps experience, platform engineering work, and cloud-native expertise.

## What the site includes

- A bold hero section introducing Aswin's focus on cloud platforms, automation, and resilient systems.
- An interactive terminal-inspired profile panel and direct contact links.
- A chronological experience timeline covering roles at Quest Global, Activelobby, and Apton Works.
- Featured project cards for the Healthcare ECG Platform, Cryptocurrency Cashback Application, and OTT Streaming & Video Analytics Platform.
- A structured technology stack covering Kubernetes, cloud infrastructure, infrastructure as code, CI/CD, and observability.
- A downloadable copy of the résumé and links to LinkedIn, GitHub, Medium, and certifications.

## Built with

The portfolio is a lightweight static website built with semantic HTML and custom CSS. It uses a responsive layout, an atmospheric grid background, terminal-style UI details, and a dark teal visual system to reflect a modern DevOps and platform-engineering identity.
